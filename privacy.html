Privacy Policy

Last updated: September 14, 2026

1. Overview

Oura Partner Mirror is a private Android application designed to allow an authorized Oura user to view selected Oura data on an Android device.

2. Oura Data

With the user's explicit authorization, Oura Partner Mirror may access selected data provided through the Oura API.

Depending on the permissions granted by the user, this may include daily sleep, readiness, activity and heart-rate data.

3. How Data Is Used

Oura data is used solely to display the authorized user's data inside the private Oura Partner Mirror Android application.

Oura data is not sold, rented, or shared with third parties through this application.

4. Data Storage

Oura Partner Mirror is designed as a client-side application. Oura data is not intentionally stored on a separate application server.

Authentication information required to access the Oura API may be stored locally on the Android device in order to maintain the connection to Oura.

5. Third-Party Services

Oura Partner Mirror uses the Oura API to retrieve data authorized by the user.

Oura Partner Mirror is not affiliated with, operated by, or endorsed by Oura Health Oy.

6. User Control

The user may revoke the application's access to their Oura data through the applicable Oura account settings.

The user may also remove the Oura Partner Mirror application and its locally stored authentication data from their Android device.

7. Data Security

Reasonable technical measures are used to protect authentication information stored by the application on the Android device.

8. Changes

This Privacy Policy may be updated if the application or its data handling practices change.

9. Contact

For questions regarding this application or this Privacy Policy, please contact the application owner.
